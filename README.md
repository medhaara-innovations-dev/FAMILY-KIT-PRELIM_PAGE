# FamilyKit Mobile React UI
Fresh React + Vite implementation based on the supplied FamilyKit mobile landing-page reference.

## Run
```bash
npm install
npm run dev
```

Then open the local URL shown by Vite (normally http://localhost:5173).

## Notes
- UI is built with real React/HTML/CSS elements; the reference PDF is not used as a page image.
- Poppins is used for headings and Mulish for body copy.
- Replace placeholder illustrative UI blocks with supplied original image assets when those assets are available.
